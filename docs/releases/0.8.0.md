# Vatilume 0.8.0 — prévia

Energia e sinais do seu PC, com histórico e evidências. Software livre e open source sob GPL-3.0-or-later, gratuito e mantido pela APFS. O apoio por Pix é opcional e não desbloqueia recursos. Não há perfil Apoia.se ou GitHub Sponsors cadastrado nesta prévia.

## Instalar

Alvo inicial: **Ubuntu 24.04 amd64**, com systemd, sessão gráfica, navegador padrão e agente polkit. Outros derivados, versões e arquiteturas ainda precisam de testes próprios.

Baixe `vatilume_0.8.0-2_amd64.deb` e `SHA256SUMS` de [Releases](https://github.com/Alexsander33set/vatilume/releases). Na pasta dos downloads:

```sh
sha256sum --ignore-missing --check SHA256SUMS
sudo apt install ./vatilume_0.8.0-2_amd64.deb
vatilume
```

Confirme `OK` para o instalador antes de executá-lo. O checksum detecta alterações, mas não substitui uma assinatura do editor, ainda não configurada. Abra também pelo menu **Vatilume**. A primeira abertura pede autorização administrativa local. Não precisa de Docker, Node, pip ou conta do projeto para usar o painel. Em navegador Snap recém-instalado, inicialize o perfil abrindo o navegador uma vez.

## O que experimentar

- Deixe o coletor registrar períodos de repouso e de uso. Fechar a aba mantém a coleta ativa.
- Compare potência, utilização e temperatura quando os sensores estiverem disponíveis.
- Configure a tarifa de energia e consulte a projeção mensal, ajustando as horas diárias.
- Consulte aplicativos que coincidem com períodos de maior demanda, com acesso aos dados de apoio.
- Se quiser usar IA, configure sua própria chave OpenAI e escolha explicitamente os limites de gasto. A instalação nova começa sem chave, com IA pausada e teto acumulado zero.

As projeções e consultas básicas funcionam sem IA. Os custos da API são pagos pelo usuário diretamente ao provedor. Não há uma chave ou saldo do projeto incluído.

## Limites desta prévia

Sensores dependem de hardware, drivers e permissões. CPU/GPU reportados não equivalem ao consumo total da tomada. A projeção mensal depende da janela observada e das horas de uso escolhidas; não prevê a conta inteira. Agrupamentos de processos são parciais, não medem watts por aplicativo e coincidência temporal não prova causa. O histórico ainda não tem expiração automática.

O painel funciona somente neste computador e compartilha o histórico entre os usuários autorizados. Não exponha a porta na internet. IA externa é opcional e envia a pergunta e recortes de evidências ao provedor; leia [privacidade](../../PRIVACY.md) antes de ativar.

## Atualizar ou remover

O mesmo comando APT atualiza o pacote existente preservando histórico, tarifa, configurações, chave e gastos. Faça um backup privado dos dados importantes. A revisão Debian `-2` prepara a documentação/metadados para distribuição; a aplicação permanece 0.8.0. A passagem de versões anteriores à 0.8 pode exigir reabrir pelo menu para renovar a sessão local.

```sh
# Remover o programa e preservar os dados para reinstalação.
sudo apt remove vatilume

# Apagar também o estado gerenciado: operação intencional e definitiva.
sudo apt purge vatilume
```

Purge não apaga backups, exportações, caches do navegador ou registros externos. Uma instalação antiga de desenvolvimento em `/opt` precisa da [migração específica](../MIGRACAO-DEB.md).

## Código, testes e ajuda

O arquivo `vatilume-0.8.0-source.tar.gz` acompanha o instalador e inclui código, fontes das dependências selecionadas, avisos, lockfiles e instruções de build. Os ZIP/tar.gz automáticos do GitHub contêm só o repositório e não substituem esse conjunto completo. Veja [fontes e reconstrução](../FONTES.md). `RELEASE-MANIFEST.json` relaciona versão, commit e hashes; `SHA256SUMS` permite conferir os downloads.

O ciclo de vida do pacote foi testado em VM Ubuntu 24.04 com systemd real. Navegadores nativos e Firefox/Chromium Snap têm ensaios de menu; detalhes em [NAVEGADORES-SNAP.md](../NAVEGADORES-SNAP.md). Isso não comprova suporte universal a hardware ou todas as sessões gráficas. O teste em outros PCs faz parte do piloto.
